# Marketing Site UI Kit

Recreation of the public-facing **supracloud.co.uk** marketing site. Single-file HTML demo at `index.html` covers the home page composition.

## What's included
- Sticky dark navbar with three multi-level dropdowns (AI Solutions / Enterprise Services / Talent Hub) per brief
- Animated terminal hero with grid + radial glow background
- Stat bar ribbon with checkmark trust signals
- Three-pillar grid (AI / IT Services / Talent)
- Interactive Industry Solution Matrix toggling Banking ↔ Retail (glassmorphism)
- Multi-column dark footer with brand, contact, sitemap
