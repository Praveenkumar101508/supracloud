# Client Portal UI Kit

Recreation of the **SupraCloud Client Portal** — the surface where active clients view delivery progress, agent metrics, and QA reports.

## What's included
- Portal-specific dark navbar with breadcrumb, "Live" status pill, account avatar
- Page header with engagement context + production status chip
- Live agent performance metric tiles (deflection, latency, uptime, volume)
- Two-column: Delivery Tracker + Programme Updates
- Delivery Reports cards (ProdReady Labs, Playwright E2E)
- Emerald Next Steps callout block
